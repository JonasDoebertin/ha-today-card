# Security Policy

## Supported versions

Today Card is a dashboard card that runs in your browser. Only the latest
release receives fixes. If you run an older version, update through HACS before
reporting a problem.

## Reporting a vulnerability

Please do not open a public issue for a security problem.

Use GitHub's private reporting instead: go to the
[Security tab](https://github.com/JonasDoebertin/ha-today-card/security/advisories/new)
of this repository and open a draft advisory. Include the version of the card,
what an attacker can achieve, and the steps to reproduce it.

Please allow up to a week for a first reply. Once a fix ships, the advisory is
published, with credit to you unless you would rather stay anonymous.
